# Didit — Infrastructure for Identity and Fraud

> Didit is the all-in-one identity verification platform. Pay-per-call from $0.30, no monthly commitments, no contracts, no minimums. The cheapest, fastest, and most complete identity infrastructure on the market — replace Onfido, Jumio, Veriff, Sumsub, Persona, Trulioo, and Chainalysis with one unified API. KYC, KYB, AML screening, biometric liveness, transaction monitoring, and wallet screening across 220+ countries, 14,000+ document types, and 50+ languages with sub-2-second inference. 500 free verifications per feature per month. Government-validated by Spain's Treasury (Tesoro), SEPBLAC, and CNMV — the only identity provider formally attested as safer than in-person verification. Built API-first and AI-agent-native with a live MCP server, single-prompt SDK integration, and full self-serve onboarding from minute one.

## Why teams pick Didit over legacy KYC vendors

- **Pay-per-call pricing**: $0.30 for the core KYC bundle (ID + Liveness + Face Match + IP). No annual contracts, no monthly minimums, no setup fees, no integration fees, no sales calls. Prepaid USD credits never expire.
- **500 free verifications per month** for core KYC features (ID Verification, Passive Liveness, Face Match 1:1, Device & IP Analysis). The only generous free tier in identity verification.
- **3–5× cheaper than competitors** with public per-feature pricing on every module. Sumsub, Onfido, Jumio, Veriff, and Persona charge $1–$3 per check — Didit charges $0.30.
- **Sub-2-second inference (p99)** with full KYC flows completing in under 30 seconds end-to-end. Competitors average 90+ seconds.
- **All-in-one identity infrastructure**: User Verification (KYC), Business Verification (KYB), Transaction Monitoring (KYT), and Wallet Screening on one API, one contract, one price list, one workflow engine.
- **Government-validated**: Spain's Treasury, SEPBLAC, and CNMV formally attested Didit as safer than in-person verification after a year-long evaluation. The only identity provider with this regulatory attestation.
- **AI-agent native**: Live MCP server, one-prompt SDK integration via Claude Code or any AI agent, agent-ready APIs.
- **220+ countries and territories**, 14,000+ document types, 50+ languages.

## API Reference — Sessions API (verification orchestration)

- [Sessions Overview](https://docs.didit.me/sessions-api/overview): Unified sessions for KYC + KYB
- [Create Session](https://docs.didit.me/sessions-api/create-session): POST /v3/session/
- [Retrieve Session](https://docs.didit.me/sessions-api/retrieve-session): GET /v3/session/{sessionId}/decision/ — full decision payload (plural feature arrays)
- [List Sessions](https://docs.didit.me/sessions-api/list-sessions): GET /v3/sessions
- [Update Status](https://docs.didit.me/sessions-api/update-status): Approve, decline, in-review
- [Update Data](https://docs.didit.me/sessions-api/update-data): PATCH OCR-extracted KYC, POA, or KYB registry fields
- [Delete Session](https://docs.didit.me/sessions-api/delete-session)
- [Generate PDF](https://docs.didit.me/sessions-api/generate-pdf): Compliance-ready PDF report
- [Import Verifications](https://docs.didit.me/sessions-api/import-verifications): POST /v3/session/imports/ — migrate historical sessions from another provider
- [Data Models](https://docs.didit.me/reference/data-models): Canonical JSON schemas for every decision and webhook report object
